# SandBox

The SandBox is an all-in-one dynamic modular synthesizer.  The user can create and wire together any combination of audio modules on the fly to make patches ranging anywhere from playable keyboards and drum machines to ambient, generative soundscapes.

The SandBox interface consists of four knobs, four buttons, and an 8x8 grid of buttons. The 8x8 grid is the user's patch-building area.  When a module in the grid selected, the four knobs will automaticaly map to that module's particular controls.  Connections are created by first pressing the source module and then the destination module.  You must connect the output signal to an 'Audio out' module for the device to output sound.
